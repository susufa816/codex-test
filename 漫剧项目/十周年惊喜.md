# 90 秒真人家庭短剧：《那条项链》

## 剧情检查

**普通观众能看懂，核心因果成立。**丈夫最近躲着看手机，妻子因此怀疑他出轨；她趁丈夫睡着查看手机，看到准备十周年惊喜的搜索记录和项链订单，误会解除；纪念日当天，丈夫送出项链，妻子笑着落泪。

**拍摄时要补足两处可见信息：**

- 前半段要让观众看见丈夫确实在躲手机，也让妻子的怀疑有依据，但不要提前透露惊喜。
- 手机内容是剧情关键，建议拍清楚手机屏幕，再后期叠加搜索记录和订单信息，别依赖生成画面里的小字。

**静音检查：**即使没有对白，只要拍清“躲手机 → 妻子起疑 → 偷看 → 看到项链订单 → 纪念日收到项链”，观众也能跟上故事。主角是妻子；她的主动查看改变了她对丈夫的判断，也让结尾有了情绪回收。

- **观众承诺：**一个怀疑丈夫变心的妻子，亲手发现这场误会背后的温柔。
- **主线：**丈夫躲着看手机 → 妻子误以为他出轨 → 她选择查看手机 → 秘密被揭开 → 十周年惊喜兑现。
- **反转铺垫：**丈夫的躲闪和妻子眼里的暧昧迹象先制造误会；手机里的搜索记录和项链订单重新解释这些行为。
- **片尾回报：**妻子拿到项链时笑着落泪；她的反应回收前面的怀疑和担心。

## 剧本

**类型：**真人家庭情感短剧  
**时长：**约 90 秒  
**建议画幅：**9:16 竖屏  
**地点：**家中客厅、卧室；纪念日晚餐桌边  
**对白策略：**少量对白，主要靠表演和道具推进  
**情绪曲线：**疑虑 → 偷看时的紧张 → 释然 → 温暖落泪

### 00–24 秒｜疑心

**00–03｜夜，客厅。**  
妻子端着两杯水走近。丈夫坐在沙发上低头看手机，妻子一出现，他立刻把屏幕扣在腿上。

妻子脚步停住，目光落在手机上。

**03–08**  
丈夫挤出一个笑，把手机拿起来，站身时顺手带走。

**丈夫**（轻松装作平常）  
我去洗漱。

妻子看着他走进卧室，手里的杯子慢慢放下。

**08–14｜卧室。**  
丈夫背对妻子，手机屏幕短暂亮起；他迅速按灭，把手机放到床头柜远离妻子的一侧。

妻子睁着眼，视线停在那部手机上。

**14–20**  
丈夫呼吸变沉，睡着了。妻子翻身，停顿一下，再轻轻坐起。

**20–24**  
她伸手拿起手机。手指在屏幕前犹豫，最后解锁。

### 24–55 秒｜真相

**24–30｜手机屏幕特写。**  
妻子先看到搜索记录。后期清晰叠字：

> “如何给老婆准备结婚十周年惊喜”

她的眉头仍没松开，继续往下滑。

**30–36**  
订单页面出现一条金项链的图片和已下单状态。手机屏幕光映在她脸上。她怔住，嘴唇微张，眼眶渐渐湿润。

**36–42**  
她回头看熟睡的丈夫。丈夫无意识地翻了个身。妻子下意识把手机护在胸前，随即意识到自己在做什么，轻轻呼出一口气。

**42–48**  
妻子把手机放回床头柜原位，确认方向和位置与原来一致。她替丈夫把滑到肩边的被子拉好。

**48–55**  
她躺回去，背对丈夫，悄悄擦掉眼泪。嘴角浮出一点笑意。切到清晨：闹钟响，她先醒来，看见丈夫还睡着，便轻手轻脚起床。

### 55–90 秒｜兑现

**55–62｜十周年纪念日晚，家中餐桌。**  
桌上有简单的晚餐和两支蜡烛。妻子望一眼丈夫，压住已经知道秘密的笑，继续布置餐桌。

丈夫从身后拿出一个小礼盒，神情有些紧张。

**62–69**  
丈夫把礼盒递给她。

**丈夫**  
十周年快乐。

妻子接过礼盒，抬眼看他，眼中含泪，但笑着点头。

**69–76**  
她打开礼盒。金项链安静躺在盒中。她指尖碰了一下项链，停住，抬头看丈夫。

**妻子**（轻声）  
你最近一直在准备这个？

丈夫先是一愣，随即明白她早已发现秘密。他有些不好意思地点头。

**76–83**  
丈夫绕到她身后，拿起项链，先让她把头发拨到一边，再替她戴上。动作轻缓，不急着扣；妻子微微低头配合。

**83–87**  
妻子摸着颈间的项链，笑着流泪。丈夫替她擦掉一滴泪，她握住他的手。

**妻子**  
我差点以为……

她没有说完。丈夫的笑意里带着歉意。

**87–90｜收尾。**  
两人额头轻轻靠在一起。镜头落在妻子握住丈夫的手、项链贴在她颈间。烛光轻晃，音乐收束。

## 角色母版

### 妻子｜主角

- **身份与目标：**结婚十周年将至；希望确认丈夫最近的反常究竟意味着什么。
- **表演线：**察觉异常时压住疑问；偷看前犹豫、反复确认丈夫是否睡着；看到订单后从紧绷转为释然；收礼时忍泪微笑。
- **外形与服装：**普通城市家庭女性，30 岁上下；居家段穿浅色针织上衣和长裤，纪念日晚餐段换成简洁的暖色连衣裙。发型、妆容自然，前后服装变化只对应时间变化。
- **声音：**平实、亲近；真相揭开后声音变轻，不用夸张哭腔。
- **连续性重点：**她知道项链惊喜的时点是夜里看完手机；纪念日时要表现为“已经知道但配合惊喜”，而不是重新震惊。

### 丈夫｜惊喜的准备者

- **身份与目标：**偷偷准备结婚十周年礼物，希望给妻子惊喜。
- **表演线：**看到妻子靠近时不自然地遮住手机；夜里担心手机被看见而把屏幕扣下；纪念日晚餐时紧张地递礼盒。
- **外形与服装：**30 岁上下；居家穿深色 T 恤，纪念日晚餐换干净的衬衫。保持普通、可信的家庭气质。
- **声音：**温和自然；“十周年快乐”说得稍微郑重，带一点期待。
- **连续性重点：**他全程不知道妻子看过订单；最终看到妻子的反应后，才意识到秘密已经被她发现。

## 道具与连续性锁定

- **手机：**同一部深色智能手机，哑光外壳；夜里放在丈夫一侧床头柜。屏幕关键信息由后期叠加，保持字大、简短、可读；不改变手机朝向和位置。
- **搜索记录与订单：**搜索句为“如何给老婆准备结婚十周年惊喜”；订单展示一条金项链和已下单状态。不要出现品牌、价格等无关信息。
- **金项链：**同一条细链金项链，单一小吊坠，置于深色礼盒内；揭晓镜头、戴上和片尾特写保持款式一致。
- **礼盒：**小型深色礼盒，纪念日晚餐段由丈夫拿出；打开后项链始终留在盒内，直到丈夫取出。

## 静音冷观众验收

静音播放时，观众应能说出：**丈夫躲着看手机，妻子怀疑他有事；她趁他睡着查看手机，发现他在准备十周年礼物；纪念日当天礼物送出，误会解除。**如果观众只看懂“妻子收到项链”，就需要把手机搜索内容和订单的画面拍得更清楚。
